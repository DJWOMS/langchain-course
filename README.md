# Код курса по LangChain

Здесь лежат запускаемые примеры из уроков курса. Папка на урок, имена файлов совпадают с именами примеров в тексте урока.

Уроки выходят по одному, и код добавляется сюда вместе с выходом урока.

## Что уже выложено

1) `lesson_00`, настройка окружения: проверочный скрипт, образец файла переменных окружения, незакреплённый набор зависимостей
2) `lesson_01`, как устроена языковая модель: токены, контекстное окно, память, температура, факты и арифметика, счёт денег
3) `lesson_02`, зачем нужен LangChain: запрос по HTTP руками, тот же вызов через фреймворк, три метода одного объекта модели, проверка старых импортов, первый агент
4) `lesson_03`, сообщения и контент-блоки: роли сообщений, content и text, стандартные блоки, рассуждение, вызов инструмента, картинка в сообщении, сохранение диалога

## Как запустить

Нужен Python 3.11 или выше.

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

На Linux и macOS окружение включается командой `source .venv/bin/activate`.

Дальше создайте файл `.env` рядом с примерами. Что в нём должно лежать, показывает `lesson_00/env_example.txt`. Ключ берётся у вашего поставщика модели, в репозиторий он не кладётся.

Проверить, что всё встало и вызов проходит:

```
python lesson_00/check_setup.py
```

## Версии

`requirements.txt` держит закреплённые версии, на которых прогонялись примеры и получен вывод, напечатанный в уроках. Поставите свежие версии, вывод может разойтись с тем, что написано в тексте.

## Про вывод примеров

Вывод в комментариях каждого файла, это результат настоящего прогона, а не придуманный текст. У вас числа будут другими: модель отвечает не одинаково, а токены и деньги зависят от вашего поставщика и тарифа.
