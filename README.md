# Код курса по LangChain

Здесь лежат запускаемые примеры из уроков курса. Папка на урок, имена файлов совпадают с именами примеров в тексте урока.

Уроки выходят по одному, и код добавляется сюда вместе с выходом урока.

## Что уже выложено

- `lesson_00`, настройка окружения: проверочный скрипт, образец файла переменных окружения, незакреплённый набор зависимостей
- `lesson_01`, как устроена языковая модель: токены, контекстное окно, память, температура, факты и арифметика, счёт денег
- `lesson_02`, зачем нужен LangChain: запрос по HTTP руками, тот же вызов с помощью фреймворка, три метода одного объекта модели, проверка старых импортов, первый агент
- `lesson_03`, сообщения и контент-блоки: роли сообщений, content и text, стандартные блоки, рассуждение, вызов инструмента, картинка в сообщении, сохранение диалога
- `lesson_04`, модель как настраиваемый компонент: три места для параметров, профиль модели, настраиваемая модель и маршрутизатор, выбор модели внутри агента, инструмент на стороне провайдера, таймаут и повторы, ограничитель частоты, счёт расхода по моделям
- `lesson_05`, системный промпт и контекст: промпт агента, что уходит в модель на каждом шаге, цена длинного промпта, промпт под роль пользователя, дописывание контекста блоками, промпт по длине разговора, примеры в промпте
- `lesson_06`, структурированный вывод: первая схема, какую стратегию выбрал агент, ToolStrategy и ProviderStrategy явно, повтор при нарушении схемы, режимы handle_errors, две схемы на выбор, схема вместе с инструментом
- `lesson_07`, стриминг: поток модели и сборка chunks, прогресс агента в режиме updates, формы v1 и v2, токены и метаданные в режиме messages, свой прогресс из инструмента, сборка сообщения в потоке, метка nostream, консольный вывод для пользователя
- `lesson_08`, поток событий stream_events версии v3: поток событий у модели, сообщения агента и имя узла model, сырые события по каналам, жизненный цикл вызова инструмента, две проекции подряд против interleave, свой преобразователь потока на вызове и в middleware
- `lesson_09`, инструменты и цикл вызова: что делает декоратор tool, цикл вызова руками, тот же цикл внутри агента, docstring и parse_docstring, схема аргументов на Pydantic, исключение в инструменте и wrap_tool_call, параллельные вызовы на одном шаге, return_direct
- `lesson_10`, ToolRuntime и Runtime: конфигурация запуска в context, что попадает в схему для модели, чтение состояния, запись в состояние с помощью Command, хранилище, Runtime и ToolRuntime в одном запуске, старые механизмы внедрения, старый способ config configurable
- `lesson_11`, первый агент: агент на create_agent, цикл модели и инструментов по шагам, сценарий и агент на одной задаче, своя схема состояния и редьюсеры, три способа остановить агента, из чего собирается харнесс
- `lesson_12`, память сессии: история одного thread, checkpoint состояния, thread на диске и режим долговечности записи, цена длинного thread, обрезка истории, суммаризация
- `lesson_13`, долговременная память: раскладка хранилища по пространствам имён, записи о человеке в системном промпте, память без отбора, профиль, запись в память по правилу, хранилище на диске и срок годности

## Как запустить

Нужен Python 3.11 или выше.

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

На Linux и macOS окружение включается командой `source .venv/bin/activate`.

Дальше создайте файл `.env` рядом с примерами. Что в нём должно лежать, показывает `lesson_00/env_example.txt`. Ключ берётся у вашего провайдера модели, в репозиторий он не кладётся.

Проверить, что всё встало и вызов проходит:

```
python lesson_00/check_setup.py
```

## Версии

`requirements.txt` держит закреплённые версии, на которых прогонялись примеры и получен вывод, напечатанный в уроках. Поставите свежие версии, вывод может разойтись с тем, что написано в тексте.

## Про вывод примеров

Вывод каждого примера напечатан в тексте урока сразу под листингом. У вас числа будут другими: модель от прогона к прогону отвечает по-разному, а расход токенов и цена зависят от вашего провайдера и тарифа.
